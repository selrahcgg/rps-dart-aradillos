## Project Description

A console-based two-player Rock, Paper, Scissors game developed using Dart.

Players enter their names and choose between rock, paper, and scissors. The program determines the winner of each round, tracks scores, and allows players to play multiple rounds.

## Features

- Two-player gameplay
- Player name input
- Rock, Paper, and Scissors move selection
- Input validation
- Case-insensitive move recognition
- Automatic score tracking
- Draw detection
- Play-again functionality
- Final score and overall winner

## Requirements

- Dart SDK
- Visual Studio Code or Command Prompt

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Execute the following command:

   dart rock_paper_scissors.dart

4. Follow the instructions displayed in the terminal.
